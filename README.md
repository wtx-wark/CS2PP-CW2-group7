## 当前实现

- 从命令行动态读取文字，按 ISO-8859-1 转换为 byte mode 数据；不支持的字符会记录失败位置和已成功编码的前缀。
- 生成 Version 1／Level L 的数据码字和 `reedsolo` 纠错码字；超过 17 字节容量时给出说明。
- 用 `numpy` 放置固定图案、数据位和格式位，应用掩码 0，并打印 21×21 的数值矩阵。
- 为题目指定的五段输入生成带中间步骤的 `demo_outputs/demo_1.txt` 至 `demo_5.txt`。

## 运行方法

课程指定 Python 3.13.9。在本目录创建虚拟环境、安装依赖并运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-cache-dir -r requirements.txt
.\.venv\Scripts\python.exe qr_version1_l_cli.py
```

输入一段文本后，程序会打印过程和最终矩阵，或清楚说明失败原因。重新生成五份示例记录：

```powershell
.\.venv\Scripts\python.exe qr_version1_l_cli.py --demo-dir demo_outputs
```

`demo_1.txt` 至 `demo_3.txt` 记录完整矩阵；`demo_4.txt` 在 `α` 处停止；`demo_5.txt` 因 25 字节超过 Version 1／Level L 的 17 字节容量而停止。日志记录了停止前已完成的步骤。

运行本阶段测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 已知限制与待确认问题

- ISO-8859-1 不能表示五段示例文本中的所有字符；本程序不会自动切换到 UTF-8。
- Version 1／Level L 的 byte mode 最多容纳 17 字节；本程序不会自动改用更高版本。
- 尚未在课程指定的 Python 3.13.9 和教学实验室电脑上验证；本地验证使用 Python 3.13.14。
- 本仓库尚未实现第二、第三阶段，也未备齐整份作业的最终文档与个人贡献材料。
